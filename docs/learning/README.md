# AI TPM Learning Notes

This folder documents the AI and AI product concepts learned while building AI Career Copilot.

## How to use this section

Each major concept should explain:

1. What it is — beginner-friendly definition.
2. Why it matters in an AI product.
3. How this project uses it.
4. A practical example.
5. Trade-offs and limitations.
6. What we learned from implementation/testing.
7. AI TPM interview takeaway.
